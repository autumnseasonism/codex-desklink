# Claude / PI 独立会话入口

0.2.1 的独立入口让 Claude 和 PI 各自先新建一条控制会话。后续消息来源指向各自入口；目标可以是任意已有的本机索引主会话，包括另一客户端创建的会话，也可以新建工作会话。来源归属和目标访问相互独立。旧入口继续使用旧配置，不自动切换正在运行的 Agent。

## 已明确开启的能力

独立配置同时开启读取、列会话、列项目、新建会话、新建项目、接续发送、查看结果。`bridge_status` 显示客户端身份、控制会话、是否需要先创建、各能力开关，以及项目连接失败的原因。

来源归属是当前安装目录内的客户端状态区分，不是操作系统权限边界。能编辑配置或状态文件的本机程序仍能改变授权；不要把安装目录提供给不受信任的程序。

## 使用流程

1. 在 Codex 中核验真实的当前聊天 ID、桌面连接、本机运行服务和允许使用的文件夹。初始化独立配置。
2. 启动 PI 或 Claude 的独立入口，检查连接。
3. 首次调用“新建会话”，命名为 DeskLink PI control 或 DeskLink Claude control，并给一个明确的初始化要求。这条聊天成为该客户端的来源入口。
4. 可以新建项目，再在该项目里新建工作会话；也可以继续新建不关联项目的工作会话。也可列出、读取和接续任意已有本机索引主会话。云端、内部子 Agent、已删除会话不在当前接口范围；归档目标须显式恢复。
5. 后续启动会沿用已保存的归属，不需要反复建立控制入口。每次提交使用新的请求编号；接受回执和执行完成是两个状态。

新建项目将一个**已有文件夹**注册为真实的 Codex 项目，只能使用配置允许的目录及其子目录。不会自动创建任意文件夹、初始化 Git 或覆盖已有内容。目录快捷方式指向范围外时同样拒绝。现有项目可以由本机负责人逐项填入 `allowedProjectIds`，无需扩大到其他项目。

新原生项目可能暂时没有出现在旧版桌面项目目录中；DeskLink 从原生接口补全目录，并在新项目里创建会话。桌面目前对旧、新项目使用不同入口：刚创建的空会话需先释放服务占用，再交给桌面执行。实现会短暂归档并恢复**这条刚创建的空会话**；不会对已有工作或控制会话使用这个过程。若中途失败，保留该会话及“不确定”请求状态；先检查状态，再由负责人决定恢复，禁止自动重复创建。

## 迁移现有客户端

保留旧配置和旧 `state/`。让正在运行的 Agent 完成当前工作；之后启动新入口或把下一次启动的注册指向新配置。无需停止其他 Claude/PI 进程。独立状态在 `profiles/state/clients/pi` 和 `profiles/state/clients/claude`，移动工具时必须保留它们。不要用旧安装脚本覆盖现有同名注册。

不同客户端仍可能同时发送到同一目标会话，最新回合的结果并非逐请求关联；接续已有聊天前先查看状态，正在运行时发送可能改变当前任务方向；确需并行开展不同工作时使用不同工作聊天。停止能力仍不支持。新建项目使用实验接口，跨桌面版本需复验。

## 未验收项的实际影响

| 项目 | 已知事实与使用影响 |
|---|---|
| 消息来源链接点击 | 原始来源 ID 已验证对应各自入口，消息投递和回复目标也已核验；实际点击未验证，可能跳错或无法导航。属于导航待验证，不能据此推断消息投递错误。 |
| 原生新项目在桌面显示 | 工具已能注册真实项目并在其中创建、接续聊天；旧桌面工具目录不识别新项目 ID。侧栏实际显示待验证，可能难以从界面找到项目或在旧项目选择器中选用；目前可以从 DeskLink 工具目录使用。 |
| 升级兼容 | 当前只验证本机版本。升级可能使索引、连接或实验项目接口变化，造成部分功能无法连接或执行；升级后先检查连接并用测试聊天复验，可能需要适配和重新核验连接。 |

建议目前优先用已有聊天和已有项目开展日常工作；新项目功能保持显式开启，但其桌面展示视为实验项。失败时先核验真实状态，避免重复创建或发送。未验证不等于已发生数据丢失，也不能保证其他版本可靠。

## Technical details / 技术细节（可跳过）

源码初始化入口为 `setup-owned-clients.mjs`；参数依次是已核验的启动聊天 ID、桌面 pipe、允许的项目根目录、本机 Codex daemon 可执行文件和 control socket。脚本创建 `profiles/pi.json`、`profiles/claude.json`、`profiles/claude.mcp.json`，拒绝覆盖已有配置，所有功能显式为 true，包括 `allowExistingConversationControl`。该开关要求独立来源模式和本机索引；旧配置缺省为 false，保留原目标限制。`ownedConversationsOnly` 是旧字段名，新开关开启后仅用于来源与状态归属，目标不再限于自己创建。`callerThreadId` 仅用于首次建会话和连接探测；工作消息来源由所属控制会话决定。

PI 使用 `start-pi-owned.ps1` / `pi-owned-extension.mjs`；Claude Code 使用 `start-claude-owned.ps1`。在仅加载指定 PI 扩展的测试中，还需显式加载 PI 的 `builtin:mcp` 扩展。源码入口与自包含包均支持；自包含包仍需本机桌面与已运行 daemon。没有新网络监听端口，不启动第二个 daemon，不编辑桌面数据库或全局设置。

项目接口适配当前本机生成的协议：`project/create`、`project/read`、`project/list`，以及为新项目创建会话的 `thread/start`、`thread/name/set`、`thread/archive`。工作执行和读回通过桌面工具完成。适配器没有对客户端开放任意协议调用。

`profiles/` 包含本机路径、连接与状态，排除于 Git 和发布包。设置文件、凭据、原始测试记录不应公开。
